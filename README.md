# NW mobile LP（公開前プレビュー）

望遠レンズ対応スマホ（vivo X300 Ultra）のレンタルを紹介するランディングページです。
提携レンタル会社のページへ送客することを目的としています。

## 公開前の状態について

- **検索よけ:** `robots.txt` と `<meta name="robots" content="noindex, nofollow">` で検索エンジンに載らないようにしています。
- **写真:** すべてイメージ写真（Unsplash のフリー素材）です。実機で撮影した作例に差し替えるまで、正式公開はしないでください。
- **未確定の箇所:** `[提携先名]`、`[倍率]`、`[会場]`、`[確認した性能を記載]` などの角かっこ部分は仮置きです。
- **リンク:** ボタンとSNSリンクの `href="#"` は、実際のURLに差し替えが必要です。

## ファイル

- `index.html` — LP本体（1ファイル完結。スマホ・PC両対応）
- `images/` — 掲載写真
- `robots.txt` — 検索よけ

## 公開の手順（GitHub Pages）

1. このリポジトリを GitHub にプッシュする
2. リポジトリの Settings → Pages で、Branch を `main` / フォルダを `/ (root)` に設定する
3. 数分後に発行される URL で閲覧できる
